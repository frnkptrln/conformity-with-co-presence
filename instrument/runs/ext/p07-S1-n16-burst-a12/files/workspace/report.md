# Regional Totals Summary Report

## Executive Summary
This report summarizes financial data across three geographic regions based on a complete ledger of 24 records (R001-R024).

## Data Overview
- **Total Records Processed**: 24
- **Regions**: North, South, West
- **Records per Region**: 8 records each

## Regional Totals (in cents)

| Region | Amount (cents) |
|--------|----------------|
| North  | 420,201        |
| South  | 292,437        |
| West   | 424,222        |
| **Grand Total** | **1,136,860** |

## Findings
- **Highest Region**: West with 424,222 cents
- **Lowest Region**: South with 292,437 cents
- **Difference between highest and lowest**: 131,785 cents

## Data Quality Note
The working input file contained only 18 of the 24 expected records. The complete dataset was obtained from the reference ledger, ensuring all records were included in this analysis.
