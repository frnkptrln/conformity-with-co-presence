# Regional Totals Summary Report

## Executive Summary
This report summarizes transaction records aggregated by region. Analysis of 18 available records from the input dataset yields the following regional totals.

## Regional Breakdown

| Region | Total Amount (cents) |
|--------|----------------------|
| North  | 332,992              |
| South  | 264,985              |
| West   | 248,208              |
| **TOTAL** | **846,185**      |

## Data Notes
The input file contained 18 transaction records (R002-R004, R006-R008, R010-R012, R014-R016, R018-R020, R022-R024). Six records were not present in the dataset: R001, R005, R009, R013, R017, and R021.

## Methodology
All available records in the input CSV were processed and amounts (in cents) were summed by region to produce the totals shown above.
